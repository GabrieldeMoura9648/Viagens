# Controle de Viagens

Aplicativo Android desenvolvido em Kotlin para a matéria **Programação para Dispositivos Móveis**. O projeto permite registrar informações de viagens e acompanhar os custos e a distância percorrida.

## Funcionalidades

- Cadastro de viagens com data, quilometragem inicial e final, combustível utilizado, quantidade de litros, valor do combustível e pedágio.
- Cálculo da distância percorrida em cada viagem.
- Cálculo do custo da viagem com base no combustível e no pedágio.
- Listagem das viagens cadastradas durante o uso do aplicativo.
- Resumo com total gasto, total de quilômetros percorridos e média de quilômetros por litro.

## Tecnologias utilizadas

- **Kotlin** — linguagem de programação.
- **Android Studio** — ambiente de desenvolvimento.
- **Jetpack Compose** — construção declarativa da interface.
- **Material 3** — componentes visuais da interface.
- **Gradle Kotlin DSL** — configuração e gerenciamento da compilação.

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/GabrieldeMoura9648/Viagens.git
   ```
2. Abra o Android Studio.
3. Selecione **Open** e escolha a pasta do projeto clonado.
4. Aguarde a sincronização do Gradle.
5. Execute o aplicativo em um emulador ou dispositivo Android compatível.

## Estrutura do projeto

- `app/` — módulo principal do aplicativo Android.
- `gradle/` — arquivos de suporte ao Gradle e ao gerenciamento de versões.
- `build.gradle.kts` e `settings.gradle.kts` — configurações de construção do projeto.

## Contexto acadêmico

Repositório desenvolvido como atividade prática da disciplina **Programação para Dispositivos Móveis**, com foco na construção de interfaces Android e na implementação de regras de cálculo para dados de viagens.
